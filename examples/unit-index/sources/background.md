# Why This Example Has Several Indexes

A logical content unit groups a deck and supporting long-form text. Its
membership does not change when several units share a physical HTML document.

The first contents list exposes the whole published unit. The second narrows
the list to literal English-tagged standard slides using named selectors.
The third deliberately matches nothing so its empty-state message is visible.

These are entry lists, not publication filters. The normal status and excluded
slide rules decide which content reaches them first. A reader's tag selection
then controls ordinary slide visibility without recomputing the index lists.
