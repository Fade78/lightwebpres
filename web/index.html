How this works Everything runs locally, inside this browser tab. The zip you upload is never sent anywhere — it is decompressed, built, and re-zipped entirely on your machine, using a copy of Python compiled to run in the browser (Pyodide, vendored in this page, not loaded from a CDN). The only network request this page makes is to load itself.

How this works Every request in this tab goes straight from your browser to the GitLab instance URL you enter below — nothing is relayed through a third-party proxy. The build itself runs locally with Pyodide, exactly like the "Upload a zip" tab.

This only works if the GitLab instance sends Access-Control-Allow-Origin on its API responses — most self-hosted GitLab instances don't, by default. If pulling fails immediately with a network error, that's almost certainly it: your GitLab admin needs to add CORS headers to the /api/ location of its reverse proxy. See specifications.md §23.10 for the exact nginx snippet.
