LightWebPres

Build a series in your browser — no install, no server.

Everything runs locally, inside this browser tab. The zip you upload is never sent anywhere — it is decompressed, built, and re-zipped entirely on your machine, using a copy of Python compiled to run in the browser (Pyodide). The only network request this page makes is to load itself.

Want to skip the zip download/upload and sync straight with a GitLab repository instead? See git-sync.html.
