LightWebPres

Sync a series with a GitLab repository, build it, and push it back — all in this browser tab.

Every request in this page goes straight from this browser tab to the GitLab instance URL you enter below — nothing is relayed through a third-party proxy. The build itself runs locally with Pyodide, exactly like the plain zip-based build page.

This only works if the GitLab instance sends Access-Control-Allow-Origin on its API responses — most self-hosted GitLab instances don't, by default. If pulling fails immediately with a network error, that's almost certainly it: your GitLab admin needs to add CORS headers to the /api/ location of its reverse proxy. See specifications.md §24.2 for the exact nginx snippet.
