# Audit LightWebPres — 2026-08-14

Audit de cohérence, de sécurité et de fonctionnalité sur l'ensemble du
dépôt (code, documentation pérenne, tests, `web/`, `tools/`, skills,
artefacts). Réalisé sur `main` @ `2f3996f` (release `v0.32.0`).

- **Périmètre** : tout le dépôt. `to-be-deleted/` consulté uniquement.
- **Méthode** : passe statique (lecture du code + greps), introspection de
  l'exécutable, sondes black-box avec fixtures hostiles temporaires (hors
  dépôt), suite de tests complète.
- **Grille de sévérité** : Bloquant / Majeur / Mineur / Info.
- **Règle** : l'audit ne corrige rien ; chaque constat propose une action.

## Constats

### Bloquant

| ID | Constat | Preuve |
|---|---|---|
| D-1 | **Le filtre de variantes ne masque pas visuellement les slides.** `applyTagFilter` pose `slide.hidden` mais le squelette CSS n'a aucune règle `[hidden]` : `.slide { display: flex }` (origine auteur) bat la règle UA `[hidden] { display: none }`. La galerie a déjà rencontré et corrigé ce piège pour `.theme-row[hidden]`. | `lightwebpres:3646-3649` vs `lightwebpres:5140` ; aucune occurrence `[hidden]` dans le CSS du deck (seules `lightwebpres:6244` et `:6278`, côté galerie). ## Ce qui est sain (échantillon vérifié)

- CLI : aliases legacy + `[WARN]`, variables d'environnement, `--version`,
  `completion`, `--format json`, tableaux d'options, parsing strict.
- Champs : cascade §20.3.1 complète, gel §20.2, conventions de nommage,
  validation `tags`/`lang_tags`/`status`/`notes_*`, bascule champ→texte.
- Références croisées : 152 références `§` résolues ; termes legacy
  confinés aux documents de renommage ; placeholders inaccessibles au
  contenu auteur (test dédié) ; aucun `eval`/`exec`/`pickle`/`shell=True`.
- Échappement : `html_escape(quote=True)` sur `src`/`href`/`title`/`alt`/
  `data-tags`/méta ; `innerHTML` absent de `web/index.html` (textContent
  partout) ; intégrité Pyodide vérifiée par la suite.
- Liens `javascript:`, labels de notes, fences `</script>`, payloads
  `settings.conf` : tous neutralisés (sondes).

   (recommandation : sanitizer amont pour le markdown tiers, ou note

4. **Mineurs** — GLOSSARY (`note`, `slide_page_numbers`), SKILL
